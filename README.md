# COVID Management System

A web-based **COVID patient management system** developed using **Python, Flask, MySQL, HTML, and CSS**. The application helps manage patient records, COVID test results, and vaccination information through a simple and user-friendly interface.

## Features

* Add, view, edit, and manage patient records
* Search and filter patients
* Track COVID test results
* Track vaccination status
* Dashboard with patient statistics
* Responsive healthcare-themed interface

## Technologies

**Python | Flask | MySQL | HTML5 | CSS3 | Git & GitHub**
